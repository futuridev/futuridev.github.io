2. Nature and Purpose of the App

PAWS is a mobile application for learning programming and robotics. The User assembles visual blocks into a program, and the App translates that program into PAWS v1.0 protocol frames that are sent over Bluetooth Classic (SPP) to a compatible ESP32-based robot owned or controlled by the User.

The App is intended for:

  • Teaching and learning programming concepts through visual blocks.
  • Controlling the User’s own educational robot.
  • Classroom, workshop, home, and hobby use.

The App does NOT connect to the internet, does not transmit data to external servers, and does not create accounts. All operation is local: the phone talks directly to the robot.

3. Key Features the User Acknowledges and Accepts

The User expressly acknowledges that the App includes the following technical features and understands their implications:

  1. Bluetooth Classic connection. The App discovers nearby Bluetooth devices and connects to the one the User selects. Pairing, when required, is handled by the Android operating system.
  2. Direct control of physical hardware. Commands sent by the App cause real, physical motion of motors, wheels, servos, and other peripherals on the robot.
  3. Safety heartbeat. While a session is active, the App sends a periodic keep-alive signal. If the robot stops receiving it, the firmware performs an automatic stop. This is a firmware-level safety aid, not a guarantee that the robot will stop in every circumstance.
  4. Pin configuration. The App can configure the robot’s hardware pins. Incorrect configuration may damage the robot, its peripherals, or connected components.
  5. Timed motor commands. Motion commands run for a duration set by the User; the robot continues moving until the duration elapses or a stop command is received.
  6. No remote kill switch. The Developer has no ability to stop, override, or intervene in a running robot. Control lies entirely with the User and the robot’s own power switch.

4. Robot Safety — User Responsibilities

Operating a physical robot carries inherent risks. The User agrees to:

  1. Supervise operation at all times, especially when the operator is a minor.
  2. Operate the robot only in a safe, clear area, away from stairs, ledges, water, open flame, animals, and bystanders.
  3. Keep hands, hair, clothing, and cables away from wheels, gears, and moving parts.
  4. Verify pin configuration and wiring before sending commands, and use a power supply appropriate for the hardware.
  5. Never operate the robot near people who cannot move away from it on their own, or in environments where a collision could cause injury or damage.
  6. Keep the robot’s physical power switch accessible so it can be turned off immediately.
  7. Not modify the robot in ways that make it unsafe (excessive speed, sharp edges, unstable loads, unsuitable batteries).
  8. Follow the safety instructions of the robot hardware manufacturer, which prevail over anything stated here in respect of the hardware itself.

The App is a control interface, not a safety system. It cannot detect obstacles, people, hazardous environments, or hardware faults.
