GhostCat Privacy Policy

Privacy Policy — GhostCat

Last updated: April 23, 2026

Overview

GhostCat is an application designed to help users quickly and easily record content they consider useful for documenting situations, preserving evidence, or keeping personal records, always at their own discretion and with respect for privacy. This Privacy Policy explains what data GhostCat accesses, how it is used, and confirms that no personal information is ever collected, stored, or transmitted by us or the application itself.

1. Information We Do NOT Collect

GhostCat does not collect, store, transmit, or share any of the following:

  • Videos or audio recordings captured through the app
  • Personal information (name, email, phone number, etc.)
  • Device identifiers (IMEI, Android ID, advertising ID, etc.)
  • Location data
  • Usage or behavioral analytics
  • Crash reports or diagnostic data sent to external servers
  • Any other form of user data

We do not operate any backend server that receives data from the application. No user data of any kind ever leaves your device.

2. Permissions Used

GhostCat requests the following device permissions solely to provide its core recording functionality:

Permission Purpose
CAMERA Access the device camera to capture video recordings
RECORD_AUDIO Capture audio alongside video recordings
FOREGROUND_SERVICE / FOREGROUND_SERVICE_CAMERA / FOREGROUND_SERVICE_MICROPHONE Keep the recording service active while in use
SYSTEM_ALERT_WINDOW Display the recording overlay on screen
POST_NOTIFICATIONS Show a notification while a recording is in progress
WAKE_LOCK Prevent the screen from sleeping during an active recording
WRITE_EXTERNAL_STORAGE / READ_EXTERNAL_STORAGE / READ_MEDIA_VIDEO Save and access recorded video files on your device

All data accessed through these permissions stays exclusively on your device. No camera feed, microphone input, or recorded file is ever transmitted anywhere.

3. Local Storage

Recorded videos are saved directly to your device’s local storage (the folder you choose). GhostCat uses AndroidX DataStore solely to persist your in-app preferences (e.g., settings you configure within the app). This data is stored locally on your device and is never synced or uploaded.

4. Third-Party Libraries & SDKs

GhostCat uses only standard, open-source Android framework libraries. Below is a complete list of the third-party and first-party libraries included in the app:

Library Vendor Purpose Data Collected
AndroidX Core, AppCompat, Lifecycle, Activity, Fragment, ConstraintLayout, CardView, Startup Google / AndroidX Android UI and lifecycle framework None
Jetpack Compose (UI, Material3, Icons) Google / AndroidX Declarative UI toolkit None
CameraX (core, camera2, lifecycle, video, view) Google / AndroidX Camera access and video capture None
DataStore Preferences Google / AndroidX Local preferences storage None (local only)
DocumentFile, ExifInterface Google / AndroidX File access and metadata handling None
Media (androidx.media) Google / AndroidX Media session compatibility None
Media3 / ExoPlayer (exoplayer, ui, datasource) Google / AndroidX Local video playback None
Kotlinx Coroutines JetBrains Asynchronous programming None
MaterialKolor Open Source Dynamic color theming None

None of these libraries include analytics, advertising, crash reporting, or any remote data collection functionality.

GhostCat does not integrate any of the following:

  • Firebase Analytics, Crashlytics, or any Firebase service
  • Google AdMob or any advertising SDK
  • Any third-party analytics SDK (e.g., Mixpanel, Amplitude, Segment)
  • Any social login or social SDK
  • Any remote logging or monitoring service

5. Children’s Privacy

GhostCat does not collect any personal information from any user, including children under the age of 13. The app is fully compliant with the Children’s Online Privacy Protection Act (COPPA) and equivalent regulations.

6. Changes to This Privacy Policy

If we ever update this Privacy Policy, we will update the “Last updated” date at the top of this document. Any changes will be published in this file before a new version of the app is released on Google Play.
